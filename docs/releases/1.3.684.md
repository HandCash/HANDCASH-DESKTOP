# 1.3.684 (1.3.683 plus the wallet-ui version bump Mobile needs)

- Reading the item basket no longer counts the whole basket on every 10-row slice; the total is counted once per page. This removes the main cause of 10–25 s storage-lock holds (lag) on large wallets.
- Not changed: skipping rows is still O(offset) per slice; a resumable cursor is the next step.
