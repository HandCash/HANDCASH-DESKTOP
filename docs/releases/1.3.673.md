# 1.3.673 — faster old HandCash collectable import

## Fixed

- Checks old-key outputs with four bounded network lanes instead of serial requests.
- Reads indexed outputs ahead while saving each chunk in its original order; pausing stops further refill.
- Looks up address holdings once instead of repeatedly searching the full list.

Signing, proof verification, and fallback checks are unchanged.

## Verification and limits

Synthetic regression coverage measures 1,000 output checks at 300 ms with mocked 100 ms requests, versus 1,000 ms for serial requests. This is not a live migration benchmark. Queue recovery across app restart is not included; do not close the app during import.

The shared wallet UI carries these changes to Desktop and Mobile. Device migration remains unverified.
