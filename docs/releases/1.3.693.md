# 1.3.693
Check for updates works in the Linux and Windows apps again: it looks up this platform's zip on GitHub releases and opens the download, and Settings shows the real app version. A failed check now shows its error instead of leaving the button gray on Checking. Activity history reads collectable records 10 at a time instead of 200, so a large collection no longer freezes the screen for about 3 seconds per batch. Linux and Windows apps on 1.3.691 or earlier need one manual download to get this.
