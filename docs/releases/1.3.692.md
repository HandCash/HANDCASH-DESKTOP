# 1.3.692
Recording how to spend a coin no longer rewrites the whole custody journal. Each send or receive used to write the full journal (2.1 MB on a busy wallet) on the UI thread; it now writes only its new records as a small file that is never edited, and folds those files together once every 32 records. Existing journals are read as they are, nothing is lost if the app stops mid-write, and every journal file still survives a wallet wipe.
