# HandCash Desktop 1.3.718

## Fixed

- Migration import resumes after a crash or restart with no skipped or duplicate items. Chosen item work is kept in a durable journal tied to one identity, account and chain; another account or chain cannot restore it.
- Imported item rows are stored per identity, account and chain. Older rows with no owner are left alone.
- After a restart, an item whose transfer was already broadcast is reported as moved. It is never rebuilt, re-signed or aborted.
- Import storage writes in 100-row slices and lets a waiting send write between slices. Finished items are looked up only for the selected outputs.

## Tests

- Crash, duplicate resume, offline, storage refusal, stale queue and post-broadcast replay tests.
- Synthetic 10,000-output benchmark (no wallet or network): four lanes 2,500ms against a 10,000ms serial model at a modelled 100ms per request; competing write waited at most 1.5ms between storage slices. Not a live or device measurement.
