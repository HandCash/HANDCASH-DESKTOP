# 1.3.694
Collectables and Activity history load much faster for large collections. Each batch now picks up after the last record it read, instead of re-reading and copying every record before it, so loading 500 collectables no longer takes minutes or holds wallet storage while a send waits. Any read that still pages the old way, or takes over 250 ms, now writes a `[list-outputs]` log line with the rows it read, skipped and returned, and log triage counts them per basket.
