# 1.3.691
Unlock no longer re-runs a refused history merge on every launch. The merge exported and parsed the whole wallet history on the UI thread each time, freezing the app for 1.5–2 s while it opened; it now waits until the account database receives a new transaction. The saved item list is written at most every 2 s instead of every 180 ms, so verification no longer blocks taps with repeated 800 KB writes.
