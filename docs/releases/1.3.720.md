# HandCash Desktop 1.3.720

Pure-Rust wallet crates, SQLite WAL storage bridge, and Dioxus Native (`handcash-native`) desktop app updates.

## Highlights

- **Rust workspace crates:** Added `handcash-primitives`, `handcash-bitcoin`, `handcash-storage`, `handcash-net`, `handcash-engine`, and `handcash-app` under `native-desktop/crates/`.
- **SQLite WAL storage bridge:** Added `StorageRustSqlite` (`packages/wallet-engine/src/storage/StorageRustSqlite.ts`) and `rustEngineBridge.ts` with non-destructive IndexedDB migration and host IPC dispatch in `native-desktop/src/bridge.rs`.
- **Native Rust UI (`handcash-native`):** Dioxus Native + Aeon UI app with shared CSS scoping (`css_scope.rs`), restored shell and titlebar brand gradients (`theme.rs`), and Settings panel section/subpage parity (`ui/panels.rs`).
- **Styling & packaging:** Shared CSS updates (`src/styles/handcash.css`, `src/styles/layout-compact.css`) and native packaging updates (`scripts/package-native-desktop.mjs`).
