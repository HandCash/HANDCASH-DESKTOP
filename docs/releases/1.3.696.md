# 1.3.696
Scrolling a wallet with many items stalls less. Item totals are counted once per storage write instead of by reading every item on each page. Records of items sent to someone else no longer carry the item's proof (the recipient gets it in the inbox message), and the proof cache that sat in UI-thread storage is gone: the app keeps the verdict and proven path, and a send rebuilds the proof from that path when it is not in memory.
