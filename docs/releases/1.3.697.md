# 1.3.697
The wallet's background checks (stale coin release, change recovery, consolidation, custody journal, sweeps, action review) read each storage row once. Paging used to re-read every earlier row to reach the next page, which grew with the square of the wallet's size; it now resumes after the last row read. Pending and failed transaction lookups ask for one status at a time through the status index instead of reading the whole transaction store, raw transactions included.
