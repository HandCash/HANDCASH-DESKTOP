# HandCash Desktop 1.3.719

Pure-Rust desktop shell release (zero Electron, zero Node runtime).

## Highlights

- **Electron removal:** Removed `electron/`, `dist-sidecar/`, `tsconfig.electron.json`, Electron-only scripts, and unused `express` / `cors` / `node-forge` dependencies. Linux and Windows ship the pure-Rust `handcash-shell`; macOS ships the Swift host with the Rust `handcash-sidecar`.
- **Rust host log privacy:** Ported `logPrivacy` into `native-desktop/src/log_privacy.rs` and wired it into `HostLog::append` so host logs redact txids, keys, handles, paymails, addresses, blobs, and amounts with parity to the renderer scrubber.
- **UI & background throttling:**
  - Async coalesced shell cache writes (`storageSetAsync`) for rebuildable caches and skipped redundant non-vault read-backs in `durable.rs`.
  - WebKit-safe `yieldToUi()` via `setTimeout(0)` on visible pages so background loops yield cleanly to WebKitGTK/WKWebView input and compositing.
  - Adaptive slice pacing (`basketSubReads.ts`), lock-free Activity worker reads (`activityLedger.ts`), zero-copy `Beef` merges (`oneSatGenesisProof.ts`), coalesced Collectables slice paints + throttled background BRC-150 walks (`collectables.ts`), and 15s round-robin `account-holding` polling (`accountMove.ts`).
- **Tooling parity:** Updated `triage-logs.mjs`, `triage/core.mjs`, `jev-brc-map.mjs`, and `jev-doc-review.mjs` for `HandCashDesktopNative` and `native-desktop/src`.
